# Pages

For daily users who want to write plans and notes next to their tasks. A Page is a markdown document owned by one Area, Project, Goal or Roadmap.

## Before you start

- An Area, Project, Goal or Roadmap to own the Page. An owner can have many Pages.

## Steps

1. Create a Page from the **+** create menu (**New page**), and give it a title.
2. Write in the editor. Type `[[` to link to any item or Roadmap: a link always shows the target's current title, and the target lists the Page under its backlinks.
3. Fold long documents into **sections**: foldable heading blocks inside the Page. Folded state is remembered per device, and sections nest two levels.
4. Attach files by dropping or pasting them into the body. An attachment is embedded in the Page.
5. Reference a Page when capturing a task with `%Page name` ([Quick add and tasks](tasks.md)).

## Verify it worked

Reload the Page and open it on a second device after syncing: the text, links and sections are the same.

## Troubleshooting

**A "Conflict copy" appeared.** The same Page body was edited on two devices before they synced. Orbit keeps both edits as sibling Pages instead of merging them; copy what you need into one and delete the other.

**A link shows an old title.** Links render the target's current title. Sync, then reload.
