# Orbit CLI

Generated by `just docs` from the clap definitions in `crates/orbit-cli`. Do not edit by hand.

## `orbit`

```text
Orbit from the terminal

Usage: orbit [OPTIONS] <COMMAND>

Commands:
  login        Sign this device in to a server. The password is read from ORBIT_PASSWORD or stdin
  logout       Sign this device out. Unsynced changes wait for the next login
  sync         Send queued changes to the server and fetch the rest
  status       Show the server, sign-in state and unsynced count
  add          Add a task
  ls           List open tasks
  next         Show what to do next
  done         Complete a task
  show         Show one task
  edit         Change a task's title or description
  search       Find tasks by words
  import       Bring data in from another app
  checkin      Check a routine in for a day (default today)
  export       Download everything as a zip: items.json, Pages as .md and attachments
  guide        Print a short reference: commands, refs, listings, JSON shapes and exit codes
  mcp          Run as an MCP server over stdio, so AI tools can use Orbit
  completions  Print shell completions to stdout
  help         Print this message or the help of the given subcommand(s)

Options:
      --json
          Print one JSON object per result, with `"v":1`, instead of text

  -h, --help
          Print help

  -V, --version
          Print version

Examples:
  orbit add "buy milk"
  orbit ls
  orbit done 1
  orbit guide
```

### `orbit login`

```text
Sign this device in to a server. The password is read from ORBIT_PASSWORD or stdin

Usage: orbit login [OPTIONS] <URL>

Arguments:
  <URL>
          

Options:
      --json
          Print one JSON object per result, with `"v":1`, instead of text

      --totp <TOTP>
          The current two-factor code, if the account has one

      --name <NAME>
          [default: orbit-cli]

  -h, --help
          Print help

Examples:
  orbit login https://orbit.example.com
  orbit login https://orbit.example.com --totp 123456
  echo "$PASSWORD" | orbit login https://orbit.example.com --name laptop
```

### `orbit completions`

```text
Print shell completions to stdout

Usage: orbit completions [OPTIONS] <SHELL>

Arguments:
  <SHELL>
          The shell to write completions for

      --json

          Print help

Examples:
  orbit completions bash > ~/.local/share/bash-completion/completions/orbit
  orbit completions zsh > "${fpath[1]}/_orbit"
```
